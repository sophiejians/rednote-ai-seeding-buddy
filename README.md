# 小红书种草搭子

面向小红书笔记阅读场景的购物决策辅助产品概念 Demo。用户可以从一篇种草笔记进入，选择自己的肤质、季节和使用场景，查看相似条件下的体验总结与对应原文，再决定是否继续了解商品。

## 项目说明

- 纯前端展示项目，不包含后端服务。
- 使用 React、TypeScript 和 Vite 开发。
- 笔记、分析、商品和互动数据均为模拟数据。
- 不连接真实 AI、商家、支付或用户账号。
- 收藏、评论与模拟购物车仅保存在浏览器本地。

## 本地运行

建议使用 Node.js 22 或更高版本。

```bash
npm ci
npm run dev
```

根据终端提示打开本地地址。

## 构建

```bash
npm run build
npm run preview
```

构建产物位于 `dist/`，可部署到支持单页应用的静态托管服务。

## 目录结构

```text
src/                 页面、交互、数据与样式
public/assets/       演示所需本地图片
index.html           页面入口
vite.config.ts       Vite 配置
```

## 主要体验路径

1. 在发现页打开第一篇粉底液笔记。
2. 点击正文下方的“种草搭子 · 适不适合我？”。
3. 选择参考条件并查看体验分析。
4. 查看结论依据、继续向点点提问或进入原笔记核验。
5. 进入试用前检查和商品展示页。

本项目为产品概念演示，不代表小红书已经上线该功能。
